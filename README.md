## 🚀 三种部署方式（任选其一）

### 方式 A：本地预览（最快，老板 Mac 上先看看效果）

```bash
cd /Users/caishen/.openclaw/workspace/projects/kid-growth-app
python3 -m http.server 8080
```

然后老板 MacBook Air 浏览器打开：http://localhost:8080

但这个只能老板本机访问，娃的平板访问不到。

### 方式 B：部署到 GitHub Pages（推荐，零成本，永久网址）

1. 在 GitHub 新建一个 repo，比如 `kid-growth-app`
2. 把这个目录的所有文件 push 上去
3. Settings → Pages → Source 选 `main` 分支根目录
4. 几分钟后得到一个永久网址：`https://<user>.github.io/kid-growth-app/`
5. 老板在娃平板 Chrome 打开这个网址
6. 菜单 → "添加到主屏幕" → 完成！图标出现在桌面，像 APP 一样用

### 方式 C：打包成 APK（想要真 .apk 文件传到平板）

去 https://www.pwabuilder.com/ ，输入上面的网址，一键打包 Android APK，下载传到平板双击安装。

## 📱 娃的平板首次使用步骤

1. 平板打开 Chrome（小米平板默认就是 Chrome）
2. 访问上面的网址

## 🎯 功能清单

### 📅 今日（默认页）
- 显示今天该做的所有任务（按分类分组）
- 点一下打卡，再点取消
- 完成有动画 + 音效 + 振动
- 顶部实时显示积分

### 📋 任务管理
- 添加任务：名字、图标、分类、分值、频率、说明
- 4 个预设分类：📚学习 / 🏃运动 / 🪥生活 / ❤️好习惯
- 支持自定义分类
- 分值：1/2/5/10 或自定义
- 频率：每天 / 工作日 / 周末 / 自选星期
- 点卡片可编辑

### 🌟 愿望清单
- 添加愿望：名字、图标、所需积分、奖励说明
- 攒够积分自动高亮"可以兑换啦"
- 点一下兑换，弹出庆祝动画
- 家长根据"奖励说明"给娃真实奖励（冰激凌/零花钱等）
- 已兑换的会显示在统计页

### 📊 成长统计
- 总积分、完成次数、连续打卡天数
- 最近 30 天打卡日历（颜色深浅表示当天完成数量）
- 分类统计（柱状图）
- 已兑换奖励列表

## 💾 数据存储

- 用 IndexedDB 存在娃的平板本地
- 换浏览器/清缓存数据会丢（暂不做云同步）
- 后续可以加"导出/导入 JSON"功能备份

---

## ⚠️ 已知限制

- iOS Safari 上 PWA 加主屏后，IndexedDB 数据可能在浏览器清理缓存时被清空（用 Android Chrome 没这个问题）
- 7 天后 Safari 会清除 Service Worker 缓存（Android Chrome 没这个限制）
- 所以选 Android Chrome 平板最稳 ✅

## 📞 技术问题排查

**平板打不开网址？**
- 检查网址拼写
- 检查平板是否连 WiFi
- 试一下 Chrome 无痕模式能不能打开

**图标没出现在主屏？**
- 必须用 Chrome，不能用小米自带浏览器
- 检查是不是点了"安装"而不是"添加到书签"

**数据丢了？**
- 别清浏览器缓存
- 别卸载 Chrome
- 别切换浏览器（要用同一个 Chrome）
